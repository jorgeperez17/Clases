# Python para Negocios, Datos e IA - sitio interactivo

Sitio web estático preparado para GitHub Pages.

## Publicar
1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `styles.css`, `app.js`, `data.js` y la carpeta `assets`.
3. Ve a **Settings > Pages**.
4. En Source selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera la URL pública.

No requiere servidor ni base de datos. El progreso del estudiante se guarda localmente en el navegador.
